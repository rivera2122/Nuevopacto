Entrar al panel

El panel guarda los cambios directamente en el repositorio de GitHub del sitio. Para entrar necesitas una llave de acceso (token) de GitHub con permiso para ese repositorio.

  1. Abre crear token en GitHub.
  2. En Repository access elige Only select repositories y marca el repositorio del sitio.
  3. En Permissions → Contents, elige Read and write.
  4. Pulsa Generate token, cópialo y pégalo abajo.

Marca esta opción solo en tu propia computadora o teléfono. El token queda guardado en este navegador y no se envía a ningún lugar salvo a GitHub.
